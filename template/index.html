Turn an old phone into an AI server.

Phonon runs an AI language model on an Android phone. Other programs on your home network can then use it, the same way they would use OpenAI's service — it offers an OpenAI-compatible API. There's no cloud and no subscription, and nothing leaves your house.

What you get

Your own AI endpoint, on a phone you already own.

Your own endpoint

The phone gets one address on your network, locked with an API key. It handles chat, streamed replies and tool calls, just like any OpenAI-style API.

The model you choose

Pick from {{ models.families }} model families ({{ models.family_labels | join(', ') }}), {{ models.size_min }} to {{ models.size_max }} each. The app downloads the model and checks that the file is correct before using it.

Works with your agents as-is

Point any OpenAI-compatible tool at it — no code changes needed. Have two phones? They can work on two tasks at the same time.

Is this for you?

Good for

Batches of agent work that run overnight. Private data that should stay in your house. Tinkering with a phone you already have.

Not for

Fast, back-and-forth chat, or models so big they need a graphics card (GPU). A phone answers one request at a time, and it is not fast.

Will my phone work?

Probably, if it's 64-bit and has the memory.

Any phone with Android {{ app.android_min }} or newer, a 64-bit ARM processor ({{ app.abi }}) and at least {{ requirements.min_ram }} of RAM for the small models should work. When the app starts, it checks the phone's processor and memory and tells you what it found. If the phone can't run a model, the app tells you why instead of just failing to start.

Set up

Three steps.

  1. Install the app. Download the APK above, or add the releases page to Obtainium.
  2. Pick a model. The app downloads it, checks its hash (a fingerprint that proves the file is intact), and starts serving it.
  3. Point your agent at it. Use http://<phone>:8080/v1 with your key. Running more than one phone? Add LiteLLM in front.

Your API key is sent unencrypted.

Phonon uses plain HTTP, not HTTPS. That means your key and everything you send cross your network without encryption. Keep the phone on a network you trust, and never open it up to the internet with port forwarding.
