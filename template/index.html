Turn an old phone into an AI server.

Phonon runs a language model on an Android phone and serves it to your own network as an OpenAI-compatible API. No cloud, no subscription, nothing leaves the house.

What you get

  • Your own endpoint. One address on your network, behind an API key. Chat, streaming and tool calls, same as any OpenAI API.
  • The model you choose. {{ models.families }} families, {{ models.size_min }}–{{ models.size_max }} each, downloaded in the app and checked before it is used.
  • Agents without changes. Point any OpenAI-compatible client at it. Two phones serve two tasks at once.

Three steps

  1. Install the app. Download the APK above, or add the releases URL to Obtainium.
  2. Pick a model. The app downloads it, checks its hash, and serves it.
  3. Point your agent at it. Use http://<phone>:8080/v1 with your key. Add LiteLLM if you run more than one phone.

opencode

A provider pointing at one phone, and an agent that stays inside it.

LiteLLM, for more than one phone

Pinned deployments so every turn of a task hits the same server's KV cache.

The API key travels unencrypted. Phonon serves plain HTTP, so the key and everything you send cross the LAN in the clear. Keep the phone on a network you trust, and never port-forward it to the internet.

Will my phone work?

Anything that runs Android {{ app.android_min }} or newer on an arm64 CPU and has the RAM below. The app checks the phone's CPU features and memory at launch and says what it found — if it cannot run a model, it tells you why instead of failing to start.

Is this for you?

  • Good for overnight agent batches, private data that should not leave the house, and tinkering with a phone you already own.
  • Not for interactive chat speed, or models large enough to need a GPU. A phone serves one request at a time, and it is not fast.
